P1 Prometheus viewer

Prometheus collects numeric measurements over time. This viewer reads the real P1 API and worker, on P1 networks only.

Open P1 viewer · Scrape targets

Try it

  1. Open scrape targets. Both bos-api at api:9464 and bos-worker at worker:9465 should show UP.
  2. In the query screen enter up and execute. Each target should return 1, meaning its latest scrape succeeded.
  3. Switch to the graph view. Use a 15-minute range; measurements arrive every 15 seconds.
  4. Try scrape_duration_seconds to see how long collection takes. This is collection time, not request latency.

Scope and access

The backend listener is 127.0.0.1:19091. Private HTTPS port 8511 uses the standard dev-share helper and private network access controls. Prometheus is stateless for browser cookies and adds no application login bypass. No Grafana is installed. Historical samples live in this viewer container; no application data or seed is changed.

Lifecycle

The container is bos-p1-prometheus-1. The active bos-p1-prometheus-viewer.service waits for that container to exit, providing the sharing lease. After a container restart, restart that lease and register the route again. No automatic boot startup is added.
