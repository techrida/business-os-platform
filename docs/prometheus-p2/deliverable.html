From the P2 checkout, load the protected runtime environment first and the nonsecret phase settings second:

docker compose --env-file /absolute/protected/p2.env \
  --env-file infra/prometheus/p2.env \
  -f infra/compose/compose.yaml -f infra/compose/compose.dev.yaml \
  --profile obs up -d --no-deps prometheus

This starts only the viewer once prerequisites are restored; it does not start exporters. Ensure the real P2 API and worker share bos-p2_backend. All host listeners must remain loopback-bound. Production Compose has no viewer port publication.

Study and acceptance

  1. Open the viewer's Targets page. Both jobs must show UP and point to the actual P2 services.
  2. In the query page, evaluate up{job=~"bos-api|bos-worker"}. Both values must equal 1.
  3. Switch to graph view and run the same query over time. A gap means no samples were collected; 0 means a scrape failed.
  4. Register the running viewer with standard dev-share, stateless, HTTPS port 8512 and its actual unit or PID lease. Check the HTTPS query page and this served guide. Never register an unrelated process to satisfy the lease.
