# Business OS platform

Techrida's Business OS (CresthaOS): a pnpm monorepo with a NestJS API, a Next.js workspace, ZITADEL login and Postgres.

## Decisions

The maintained [P0-P4 decision register](docs/decisions/README.md) separates confirmed answers, defaults and open questions. [Open the offline questionnaire](docs/decisions/deliverable.html) to draft and export answers. Update affected decision IDs in each phase PR and reconcile them when merging.
